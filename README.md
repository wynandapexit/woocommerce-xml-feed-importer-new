# WooCommerce XML Feed Importer

This plugin imports product data from XML and CSV feeds into WooCommerce. It includes:

- manual trigger buttons in the WordPress admin
- optional scheduled imports via WordPress cron
- support for XML and CSV feeds
- flexible field mapping and XPath extraction
- authentication options for API keys, Basic Auth, Bearer tokens, and custom headers

## Requirements

- WordPress 5.0+
- WooCommerce 3.0+
- PHP 7.4+

## Installation

1. Copy the plugin folder into `wp-content/plugins/`
2. Activate the plugin in WordPress
3. Configure your feeds under WooCommerce > XML Feed Importer
4. Use the Trigger button to run imports immediately
